# Carlos B. Vasquez — Professional Portfolio

Static recruiter-focused portfolio built with:

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

## Structure

- `index.html` — main page
- `css/style.css` — styling
- `js/script.js` — profile-image preview, mobile menu, dynamic year
- `assets/profile-placeholder.svg` — replace with your profile photo

## GitHub Pages

For a user site, GitHub Pages expects a repository named `<username>.github.io`. The site entry file can be `index.html`.

Replace the placeholder profile image with your own photo, and optionally add `resume.pdf` to the root.
